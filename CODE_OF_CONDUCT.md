# Community Conduct

Treat contributors and users with respect. Discuss ideas and code on their merits, welcome different experience levels, and give actionable feedback. Disagreement is welcome; personal attacks, harassment, discriminatory remarks, threats, and publishing another person's private information are not.

Keep issues and pull requests relevant to the project. Do not post credentials, private server data, or material you lack permission to share. Respect maintainers' time by providing reproduction details and keeping discussions focused.

Maintainers may edit or remove inappropriate content, close disruptive discussions, and restrict participation when necessary. They should explain moderation decisions when doing so does not expose private information and apply these expectations consistently, including to themselves.

Report conduct concerns privately to a maintainer using a contact method they have made available on GitHub. Avoid posting sensitive details in a public issue. This policy applies to project issues, pull requests, discussions, and other spaces managed by the project.

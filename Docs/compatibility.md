# Game compatibility

Community pull requests can document tested game builds, file variants and operating systems.

## Report format

Include:

- Game/client/server edition and build.
- Application version or commit and OS/architecture.
- Client or server file variant and how the source file was produced.
- Import, edit, undo/redo, save/reopen and export steps performed.
- Expected and observed behavior in the game.
- A minimal redistributable example and expected values when available.
